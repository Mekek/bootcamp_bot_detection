# Детекция ботов по событиям

Решение тестового задания Avito DS Bootcamp.

Задача: для каждой cookie из `test.csv` посчитать `score` от 0 до 1. Чем score выше, тем больше похоже, что это бот.

Основная метрика - `Precision` при `Recall >= 0.70`. Метрика считается на уровне cookie, а не на уровне отдельных событий.

## Что внутри

- `solution.ipynb` - основной ноутбук с решением.
- `metric.py` - официальная метрика из задания.
- `submission.csv` - финальный файл с предсказаниями.
- `data/train.csv` - обучающая выборка.
- `data/test.csv` - тестовая выборка.
- `data/events.csv.gz` - события.
- `sample_submission.csv` - пример формата ответа.

## Идея решения

Сначала я оставляю только события внутри окна наблюдения:

```text
window_start_ts <= event_ts < window_end_ts
```

Потом для каждой cookie собираю признаки:

- сколько всего было событий;
- сколько разных объявлений, категорий, локаций и запросов;
- какие типы событий встречались;
- как быстро шли события друг за другом;
- были ли короткие паузы и длинные паузы;
- сколько было сессий;
- какие platform, браузер и ОС были в user-agent;
- простые флаги из user-agent вроде `python`, `curl`, `selenium`;
- статистики по координатам курсора;
- глубина поиска.

В модель не передаю `cookie_id` и сырые `item_id`. По ним считаются только агрегаты.

Модель - простой ансамбль из трех моделей sklearn:

- `ExtraTreesClassifier`;
- `HistGradientBoostingClassifier`;
- `RandomForestClassifier`.

Их предсказания усредняются с фиксированными весами.

## Локальная проверка

Так как test идет позже train, валидация тоже сделана по времени.

Для сравнения я посчитал простой baseline: RandomForest только на двух признаках
`n_events` и `n_items`. Он получился слабым, зато видно, что новые признаки реально
помогают.

| Сплит | Baseline | Основная модель |
|---|---:|---:|
| с 2026-04-17 | 0.0931 | 0.7671 |
| с 2026-04-18 | 0.0980 | 0.7204 |
| с 2026-04-19 | 0.0823 | 0.7674 |

Это не гарантия такого же результата на скрытом тесте, но такая проверка ближе к реальной ситуации, чем случайный split.

## Как запустить

```bash
pip install -r requirements.txt
```

Потом открыть `solution.ipynb` и выполнить все ячейки.

После запуска появится новый `submission.csv`.

Формат ответа:

```text
cookie_id,score
```

В файле должна быть ровно одна строка для каждой cookie из `data/test.csv`.
